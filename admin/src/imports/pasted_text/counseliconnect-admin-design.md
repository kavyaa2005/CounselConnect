Design a premium, modern, fully interactive Admin Dashboard for CounseliConnect, an Online Counseling Management System. The design should feel like a high-end SaaS product used by healthcare and mental wellness organizations. Prioritize trust, clarity, accessibility, and a polished professional appearance. Every screen must be connected through clickable navigation with smooth prototype transitions. The design should be responsive, visually consistent, and ready for developer handoff.

Overall Design Style

Create a clean, elegant interface inspired by Linear, Notion, Stripe Dashboard, Vercel, Headspace, and modern healthcare platforms.
